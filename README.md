# 豆包输入法无障碍模块（DoubaoA11y）1.2.0

让视障用户能用读屏（TalkBack、点明、保益、天坦、解说等）使用豆包输入法。

- 适配版本：豆包输入法 1.5.4、1.5.5。豆包升级到其他版本后部分功能可能失效，设置页状态里会提示。
- 安装方式：LSPosed（要 root）或 LSPatch（免 root）。
- 只在读屏开着时工作，不开读屏时豆包和原来一样。
- 出错只记日志，不会让输入法崩溃。

## 一、怎么用

读屏焦点一直留在编辑框，不会跳进键盘。

- **摸着读，抬手输入**：手指在键盘上滑，摸到哪个键就读哪个键，手指停在键上抬起就输入。滑出键盘再抬手，不输入。
- **候选栏、工具栏、更多候选**：一样是滑过去读，抬手选中或点击。打拼音时会自动读第一个候选，单字带解释，比如“高，提高的高”；他、她、它照 NVDA 的说法读：他们的他、女她的她、其他的它。解释用词以 NVDA 的字符描述为主，收录约一万二千字，会避开同音词。
- **逗号、句号切换候选**：打拼音时逗号键是“上一个候选”，句号键是“下一个候选”，切到哪个读哪个，按空格上屏。可在设置里关掉。打拼音时停在空格上不开始语音。
- **删除键**：手指停住一会儿（默认 1.5 秒）开始连续删除，抬手停止。
- **空格键**：手指停住一会儿（默认 1 秒）开始语音输入，说完再一起上屏（说话时读屏不会一直读编辑框）。说话时手指滑到左上方读“松手撤回输入”，右上方读“松手一键发送”，回到中间读“松手结束”，抬手就按当前位置执行。
- **符号栏**：九键、数字键盘左边的符号每个单独读。
- **豆包菜单、剪贴板、常用语**：交给读屏焦点，打开后焦点落到第一项，左右滑动浏览。菜单底部有“下一页”（最后一页是“上一页”）按钮，双击翻页。
- **提示**：切换键盘、大小写时读出新状态；键盘收起时读“键盘已收起”。
- **震动**：摸到按键、换到另一个按键时轻震一下。
- **标准输入**：不习惯抬手输入的话，设置页“输入方式”选“标准输入”，摸到键先读，双击才输入。这时不用快速打字。
- **九键读数字**：九键拼音的 abc 键读 2，wxyz 键读 9，像讯飞那样。按键上方上滑输入的小字不再读。
- **快速打字**：用天坦或解说时，模块会请读屏把键盘区域的触摸直接交给输入法，开着触摸浏览也能快速打字，不会被当成双击。打开菜单、剪贴板、定制工具栏时自动恢复读屏焦点浏览。其他读屏不受影响。
- **读屏开着、触摸浏览关着**：键盘仍然是按下滑动朗读、抬起输入。删除键、空格键默认也由模块处理（抬手输入，停住连续删除或语音），可以在“输入方式”页的“快速输入”里改回豆包原生操作。菜单、剪贴板、常用语用豆包原来的操作。豆包自带的滑动手势这时不能用。

## 二、定制工具栏

“菜单 → 定制工具栏”交给读屏焦点，左右滑动浏览，打开后焦点落在第一个可选工具。

- 可选工具：每个读“名字，已添加”或“名字，未添加”，双击添加或移除，会读出“已添加剪贴板”“已移除剪贴板”。
- 最上面一排对应键盘上方的工具栏：“完成”双击结束编辑；已添加的工具读“名字，已添加，双击移除”。
- 底部有“下一页”（最后一页是“上一页”），双击翻页。
- “靠左吸附”“靠右吸附”会读出哪个已选中。

## 三、编辑面板

豆包没有编辑面板，模块把豆包的“单手模式”工具改成了编辑面板。

- 打开方式：在“菜单 → 定制工具栏”里添加“单手模式”（模块读作“编辑面板”），工具栏上就有了。菜单里的“单手模式”“移动光标”也会打开编辑面板。
- 三行五列：
  - 第一行：Tab、复制、上移、粘贴、删除
  - 第二行：开头、左移、选择、右移、向后删除
  - 第三行：末尾、全选、下移、剪切、返回
- 左移、右移会读出光标越过的字，到头时读“已到开头”“已到末尾”。
- 点“选择”开始选择，再用移动按钮扩大选择，会读出已选的内容；再点一次“选择”取消。
- 点“返回”回到键盘，收起键盘时面板也会关掉。

## 四、调整键盘和豆包设置

- **调整键盘**：豆包的“调整键盘”界面原来要拖动边缘，模块在上面盖一层按钮：增高、降低、上移、下移、加宽、变窄、左移、右移、重置、读大小、完成。每点一次调一小段，读出键盘占屏幕的高度和宽度。
- **分档滑块**：豆包设置里的候选字大小等滑块，读屏可以用调节手势换档，读出当前档位。

## 五、设置页

打开桌面上的“豆包输入法无障碍”。第一次打开（和模块更新后第一次打开）会全屏显示“使用须知”，点“同意”才能用，点“不同意并退出”直接关掉。之后打开时会自动查一次状态并读出：模块是否生效、豆包版本对不对、读屏和触摸浏览开没开。改动马上生效，不用重启。

首页从上到下：状态（豆包里还在运行旧版模块时会出现“去强行停止豆包输入法”按钮，读屏没开时出现“打开无障碍设置”）、查询模块状态、当前版本和检查更新、各设置入口，最下面是作者、QQ 群和 GitHub 地址。每个入口是单独一页，返回手势回首页；开关下面一行是提示。

- **检查更新**：从 GitHub 下载最新版模块并安装；已是最新也会弹窗说明。更新后一定要强行停止一次豆包输入法。
- **输入方式**：抬手输入或标准输入；删除键、空格键的停留时间（0.5 到 5 秒，只在触摸浏览开着时有效）。
  - **快速输入**（在输入方式页里）：键盘响应更快，天坦和解说原生支持，其他读屏在关闭触摸浏览时使用。可以把空格、删除键分别改成豆包原生操作（默认关）。
- **候选与朗读**：字词解释；逐字解释字数（全部或 1 到 5 个字，默认全部）；逗号、句号切换候选。
- **提示与震动**：切换键盘类型、大小写状态时提示（默认关）；键盘弹出时朗读键盘类型；键盘关闭时提示；触摸震动和强度。
- **自定义解释词**：列出全部单字解释，每个一行，顶上可以搜索。点一行改这个字用的词，也能给没有解释的字加上。
- **使用帮助**：在应用里看使用说明，按章节标题跳转。
- **高级**：调试选项（平时收起，发日志时才打开）；全部恢复默认（不影响自定义解释词）。

如果状态读“模块没有回应”：先在任意输入框弹出一次豆包键盘，再点“查询模块状态”。仍然不行，检查 LSPosed 或 LSPatch 里的作用域，然后强制停止豆包输入法。

## 六、安装

### LSPatch（免 root，已在小米澎湃安卓 16 上验证）

1. 安装 LSPatch 管理器（JingMatrix/LSPatch，GitHub Releases 里的 manager-…-release.apk）和本模块 APK。
2. 小米澎湃系统要先给 LSPatch 开“获取应用列表”权限，否则选应用时列表里只有它自己。顺便打开 LSPatch 的自启动。
3. LSPatch → 底部“管理” → 右下角加号 → “选择已安装的应用程序” → 选“豆包输入法”。
4. 修补模式选“本地”，其他保持默认，点“修补”。
5. 修补完点“安装”。签名变了，要先卸载原版豆包，本地词库和登录会丢，需要的话先开云同步。
6. 装好后重新启用豆包输入法并设为默认。
7. LSPatch → “管理” → 点“豆包输入法” → “模块作用域” → 勾选“豆包输入法无障碍”。然后强制停止豆包一次。
8. 别卸载 LSPatch：本地模式下豆包启动时要用到它。模块不生效时检查 LSPatch 的自启动和后台限制。

更新模块：直接安装新版模块 APK，再强制停止豆包输入法即可，不用重新修补。

### LSPosed（要 root）

1. 安装模块 APK。
2. LSPosed 管理器 → 模块 → 豆包输入法无障碍 → 启用，作用域只勾选“豆包输入法”。
3. 强制停止豆包输入法，或者重启手机。

## 七、注意事项

- 字节的风控可能检测到签名变化（LSPatch）或 Xposed，可能导致登录异常、云同步或语音不能用。遇到请记下现象。
- 豆包升级后，第一次弹出键盘会读一次版本提醒，设置页状态开头也会说“注意”。这时最好先别升级，或者等模块更新。
- 日志：模块默认不记运行日志（运行日志会记下按键和语音文字）。遇到问题想反馈时，打开设置页“调试选项”里的“记录运行日志”，复现一次，用电脑执行 `adb logcat -s DoubaoA11y > doubao_log.txt` 保存日志，用完记得关掉。日志里可能有你输入的内容，发给别人前先看一遍。
