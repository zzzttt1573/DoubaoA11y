这是什么

这个模块让读屏用户（解说、TalkBack、点明、保益、天坦等）能用豆包输入法。不用 root。
适配豆包输入法 1.5.4，其他版本部分功能可能失效。

一、包里有什么

1. 1-LSPatch管理器.apk
   用来把模块装进豆包。LSPatch 是开源工具（GPL-3.0 许可，作者 JingMatrix，项目地址 github.com/JingMatrix/LSPatch）。

2. 2-豆包无障碍模块.apk
   本模块。装好后桌面上有“豆包输入法无障碍”图标，是设置页。

3. 使用说明.txt
   就是本文件。

包里不含豆包输入法。请先从应用商店，或者 QQ 群“乐天的居家小屋”（1135031490）安装豆包输入法官方版本。


二、安装前要知道

1. 装好后不要卸载 LSPatch 管理器，豆包每次启动都要用到它。
2. 装好后不要在应用商店里升级豆包，升级会把修补去掉，而且新版本不一定适配。


三、安装步骤

第 1 步：安装两个 APK
  先装“1-LSPatch管理器.apk”，再装“2-豆包无障碍模块.apk”。
  手机提示“禁止安装未知来源应用”时，按提示允许即可。

第 2 步：给 LSPatch 开权限
  打开 设置，进 应用设置（或 应用管理），找到 LSPatch，进 权限管理，
  打开“获取应用列表”（也叫“读取应用列表”）。
  再在 LSPatch 的应用详情里打开“自启动”，省电策略选“无限制”。
  不开“获取应用列表”的话，下一步选应用时列表里只有 LSPatch 自己。

  补丁：荣耀手机在权限管理里找不到“获取应用列表”，解决方法：
    1. 打开 LSPatch，点底部的“管理”。
    2. 上滑回到桌面，一定要让 LSPatch 留在后台。
    3. 随便卸载一个其他应用。
    4. 回到 LSPatch，就会弹出申请获取应用列表的提示框，允许即可。
  荣耀真的 666，搞得跟献祭仪式似的。

第 3 步：修补豆包
  1. 打开 LSPatch。
  2. 点底部的“管理”。
  3. 点右下角的加号按钮。
  4. 选“选择已安装的应用程序”，在列表里找到“豆包输入法”并点它。
     别选错了，是豆包输入法本身，不是“豆包输入法无障碍”。
  5. 修补模式选“本地”。其他选项保持默认。
  6. 点底部的“修补”，等它完成。

  补丁：修补模式选“本地”装好后用不了的话，就改选“集成”重新修补。
  集成的缺点是每次模块更新之后，都要重新集成一次。

划重点！！最重要的一步！！！
第 4 步：安装修补后的豆包
  1. 修补完成后，千万不要点底部的“安装”。
  2. 去手机桌面，把豆包输入法卸载了。
  3. 回到 LSPatch，这个时候再点“安装”，跟着安装程序装好。

第 5 步：启用模块
  1. 回到 LSPatch，点底部“管理”。
  2. 在列表里点“豆包输入法”，选“模块作用域”。
  3. 勾选“豆包输入法无障碍”，点右下角的“应用”。
  4. 打开 设置，进 应用设置，找到豆包输入法，点“强制停止”。

第 6 步：确认生效
  1. 在任意输入框弹出一次豆包键盘。
  2. 打开桌面上的“豆包输入法无障碍”。第一次打开会全屏显示“使用须知”，读完点“同意”；点“不同意并退出”会直接关掉。
  3. 打开时会自动读出状态。读到“模块已生效”就成功了。
  4. 如果读到“模块没有回应”：先弹出一次豆包键盘，再点“查询模块状态”。
     还不行就回到第 5 步检查勾选，再强制停止豆包一次。


四、怎么用

先去豆包输入法的设置里浏览一下，调整一下键盘设置。推荐在“布局与显示”里：
  1. 定制工具栏；
  2. 字大小调整到最大；
  3. 键盘布局选择逗号、句号分开。
其他设置根据喜好自行调整。

常用操作：
1. 空格键：手指停住一会儿（默认 1 秒）开始语音输入，说完再一起上屏，说话时读屏不会一直读编辑框。说话时手指滑到左上方是“松手撤回输入”，右上方是“松手一键发送”，中间靠下是“松手结束”，抬手就执行。
2. 九键、数字键盘左边的符号栏：每个符号单独读，手指停在最下面一格会自动往下翻，停在最上面一格往回翻。
3. 不习惯抬手输入的话，在“豆包输入法无障碍”设置页的“输入方式”里选“标准输入”：摸到键先读，双击才输入。
4. 九键拼音的按键像讯飞那样读数字：abc 键读 2，wxyz 键读 9。
5. 觉得键盘太小，可以在豆包菜单里的“调整键盘”里调整。


五、设置页

打开桌面上的“豆包输入法无障碍”就是设置页。首页显示模块状态、当前版本和“检查更新”按钮，下面有六个入口：
1. 输入方式：选抬手输入或标准输入；调删除键、空格键的停留时间；“快速输入”里可以把空格键、删除键改为豆包原生操作，键盘响应更快。
2. 候选与朗读：字词解释、逐字解释字数、逗号句号切换候选。
3. 提示与震动：切换键盘类型和大小写状态时提示、键盘弹出时朗读键盘类型、键盘关闭时提示、触摸震动和震动强度。
4. 自定义解释词：打拼音时单字读成“字，某某的字”，在这里可以改成你自己习惯的说法。
5. 使用帮助：就是本说明。
6. 高级：调试选项和全部恢复默认，平时用不到。

键盘布局、豆包自己的震动和声音，请在豆包输入法 app 里调整。


六、更新模块

以后有新版模块，可以在设置页点“检查更新”，也可以直接安装新的“豆包无障碍模块.apk”覆盖。装好后强行停止一次豆包输入法即可，不用重新修补（修补模式选了“集成”的，要重新集成一次）。更新后第一次打开“豆包输入法无障碍”会再显示一次“使用须知”。
连不上 GitHub 的话，可以加入 QQ 群“乐天的居家小屋”（1135031490）获取最新版。


七、常见问题

1. 模块突然不生效：检查 LSPatch 有没有被系统清理，打开 LSPatch 的自启动，省电策略设为无限制。
2. 豆包被商店升级了：模块会读一次版本提醒，部分功能可能失效。可以卸载豆包，装回 1.5.4，再从第 3 步重新修补。
3. 设置页读到“模块没有回应”：可能是模块没有生效。先在任意输入框弹出一次豆包键盘，再点“查询模块状态”；还不行就到 LSPatch 里确认豆包输入法的模块作用域勾选了本模块（见第 5 步），再强行停止一次豆包输入法。
